# Support

- **Your Moveworks instance's Conversations API setup** (enablement, the chatbot, credentials, rate limits, feature availability): contact your Moveworks account team, or Moveworks Support at [support@moveworks.ai](mailto:support@moveworks.ai).
- **How the API behaves**: see the [Conversations API documentation](https://docs.moveworks.com/api-reference/conversations-api/overview).
- **Bugs or gaps in this starter code**: open a GitHub issue on this repo. Issues are answered on a best-effort basis.
- **Security-sensitive reports**: see [SECURITY.md](SECURITY.md). Do not open a public issue.

## Disclaimer

This repository is reference code, provided as-is under its license. It is not a supported Moveworks product and carries no SLA. The Conversations API is in Controlled Availability and its behavior can change; verify against the [official documentation](https://docs.moveworks.com/api-reference/conversations-api/overview) before using patterns from this repository in production.
